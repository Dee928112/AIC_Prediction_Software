# AIC-Prediction Software

This software is developed for predicting and interpreting the mechanical strength and thermal conductivity of aerogel-incorporated concrete.

## Download

Please download `AIC_Prediction.zip` from the **Releases** section.

## How to use

1. Download `AIC_Prediction.zip`.
2. Unzip the file.
3. Open the `AIC_Prediction` folder.
4. Double-click `AIC_Prediction.exe`.

## Important notes

Please do not delete or move the `_internal` folder, `outputs` folder, or `.pkl` files. These files are required for the software to run.

The `.pkl` files are external model files. If the models are updated, replace the corresponding `.pkl` files with the same filenames.

The software may briefly display a console window during SHAP explanation generation. This does not affect the prediction results.
